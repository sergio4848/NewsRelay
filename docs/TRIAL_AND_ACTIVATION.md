# Trial and activation

First run shows licensing guidance. Only an explicit Start 7-Day Trial request calls provider trial activation. Installation, browsing Settings, demo selection, startup and refresh never start a trial. No customer email/company input is required for evaluation.

The provider validates the machine and returns signed trial expiry. Trial state is independent of editorial/demo databases. Expiry preserves sources, themes, rundown and history; it locks new operational work. A paid key activates a provisioned license. Password-style key input is cleared immediately on submission and is never returned, logged, exported or cached by NewsRelay. The SDK owns its encrypted activation store.

Settings → License provides trial start, activation, refresh, current activation ID/count/limit when supplied by the provider, expiry/grace dates and deactivation with confirmation. Unknown values display as unavailable, never invented. Enterprise pilot is a provisioned license using the same activation flow.

Offline grace is valid only while the SDK verifies the existing activation and its signed finite grace/expiry permits use. Clock anomalies require correcting system time and refreshing. Outages do not discard existing Program. Explicit CLEAR is still available. License/contact/diagnostics/export remain available after expiration.
