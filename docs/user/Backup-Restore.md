# Backup / Restore — Yedekleme

Settings exports versioned portable configuration: sources, groups/trust, blocked terms, theme, language and duration. Credentials are excluded. Imports validate the format, require deliberate replacement confirmation, clear Program and disable Auto-Air permissions. Re-enter credentials securely.
To retain actual Incoming/rundown/history, fully exit NewsRelay and copy its Windows application-data folder to a private backup. Restore only while the application is closed and preserve the same Windows user account for encrypted credentials. Portable config alone is not a history backup. Do not send the database to public repositories or diagnostics channels.
Legacy tracking import reads tracking.json only. It does not read .env, import credentials or reproduce forced automatic publication.
Türkçe: Ayarlar’dan taşınabilir yapılandırmayı dışa aktarın. Kimlik bilgileri dahil edilmez. İçe aktarma yayını temizler ve otomatik yayın izinlerini kapatır. Haber/geçmiş yedeği için uygulamayı kapatıp Windows uygulama-verisi klasörünü özel bir konuma kopyalayın. Şifreli kimlik bilgileri aynı Windows hesabına bağlıdır.
