# Troubleshooting / Sorun giderme

No stories: verify Enabled, endpoint/handle, stored credential, blocked terms and source health. A provider may require a paid plan or return rate limits. Requests time out and back off; repeatedly pressing Check sources can consume provider quota.
No OBS graphic: confirm Program is active, use the current workspace URL, set 1920×1080 and refresh. Test URL always shows fictional content. A different application using NewsRelay's persisted port prevents startup; stop the conflicting service before reopening.
No auto progression: check mode, source permission, trust, minimum priority and HOLD. Restart intentionally returns to Manual.
Startup/storage error: confirm the Windows user-data folder is writable and not in use by another instance. Do not delete the database to bypass a schema error; restore a private backup or use the matching application version.
Türkçe: Haber gelmiyorsa etkinliği, adresi, kimlik bilgisini, engellenen ifadeleri ve kaynak durumunu kontrol edin. OBS için doğru çalışma alanı adresini ve aktif Yayın içeriğini doğrulayın. Otomatik geçiş için izin, güven, öncelik ve sabitlemeyi kontrol edin. Veritabanı hatasında dosyaları silmeden özel yedeğe veya desteğe başvurun.
