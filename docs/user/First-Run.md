# First Run / İlk çalıştırma

Choose English or Türkçe in the welcome strip. Start the trial explicitly or activate your license in Settings → License. Then configure a source, visit Settings for OBS, choose colors under Templates and copy the test-output URL. Finish setup when ready.
For an offline rehearsal with valid access, switch to Demo mode and confirm. Demo has fictional stories and a separate database. Clear Program before switching workspaces; each workspace has its own output URL. Nothing in the live workspace is populated with demo stories.
Türkçe: Karşılama alanında dili seçin. Ayarlar → Lisans bölümünden denemeyi başlatın veya lisansınızı etkinleştirin. Sonra kaynakları, OBS çıkışını ve temayı ayarlayın. Test adresini OBS’ye ekleyerek kontrol edin. Demo da geçerli lisans gerektirir ve kurgusal haberlerle ayrı bir veritabanında çalışır. Çalışma alanı değiştirmeden önce yayını temizleyin; her alanın çıkış adresi ayrıdır.
