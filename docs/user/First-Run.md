# First Run / İlk çalıştırma

Choose English or Türkçe in the welcome strip. Configure a source, visit Settings for OBS, choose colors under Templates and copy the test-output URL. Finish setup when ready.
For an offline rehearsal, switch to Demo mode and confirm. Demo has fictional stories and a separate database. Switching workspaces blanks output; each workspace has its own output URL. Nothing in the live workspace is populated with demo stories.
Türkçe: Karşılama alanında dili seçin. Kaynakları, OBS çıkışını ve temayı ayarlayın. Test adresini OBS’ye ekleyerek kontrol edin. Demo modu kurgusal haberlerle ayrı bir veritabanında çalışır. Çalışma alanı değişince yayın temizlenir; her alanın çıkış adresi ayrıdır.
