# Preview and Program / Önizleme ve yayın

Selecting a story prepares Preview. Edit headline/content, choose a template and Save. TAKE copies prepared content into Program. Subsequent Preview changes do not rewrite the item already on air. New story creates a manual editorial preview without putting it on air.
HOLD prevents TAKE, NEXT and automatic changes while sources continue receiving stories. Release restarts the display duration. CLEAR asks for confirmation, blanks Program and selects Manual. Keyboard shortcuts work outside text fields: Ctrl+Enter TAKE; Ctrl+H HOLD; Ctrl+N NEXT; Ctrl+Shift+Backspace CLEAR.
Türkçe: Habere tıklamak yalnızca Önizleme’yi değiştirir. Düzenleyin, şablonu seçin ve YAYINA AL’a basın. SABİTLE, otomatik ve manuel geçişleri engeller. Serbest bırakınca süre yeniden başlar. YAYINI TEMİZLE onay sonrası çıkışı kapatır ve Manuel moda döner.
