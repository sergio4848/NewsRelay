# Themes / Temalar

Templates contains Headline, Breaking, Quote, Media and Ticker. The monitor uses the selected Preview or first Incoming item. Switch to Demo if you need offline examples.
Set customer name, HTTPS logo URL, surface/accent colors, lower-third label and scale. Save applies these shared theme settings to output. Test changes before live use: saved theme changes affect Program styling. Fonts use the Windows system stack; custom font files and arbitrary HTML are not accepted.
Media uses a contained image/video area; unsupported or failed assets fall back to text. Video is muted and loops. Interactive legacy play/pause/volume controls are not part of this release.
Türkçe: Şablonlar bölümünde görünümü seçip kurum adı, logo, renkler, etiket ve ölçeği ayarlayın. Kaydedilen tema yayındaki grafiği de değiştirir. Medya yüklenemezse metin gösterilir. Videolar sessiz döngüde oynar.
