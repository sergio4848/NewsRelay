# Installation / Kurulum

Run NewsRelay-Setup-5.1.0.exe. Choose a per-user installation folder and launch NewsRelay from Windows. Node.js and npm are included within the application runtime; no separate installation is needed. Ask the vendor for a configured installer; the public engineering build intentionally denies operational use until its product configuration is supplied. Start your evaluation or activate your license after launch.
This build is unsigned. Obtain it from the owner and follow your organization's software policy. No automatic update service is active. Exit NewsRelay before installing a newer owner-provided build. The uninstaller retains operational data.
Türkçe: Kurulum dosyasını çalıştırın, kullanıcı klasörünü seçin ve NewsRelay’i açın. Ayrı Node.js kurulumu gerekmez. Bu paket imzasızdır; kurumunuzun kurulum politikasını uygulayın. Güncelleme öncesi uygulamayı kapatın. Kaldırma işlemi çalışma verilerini silmez.
