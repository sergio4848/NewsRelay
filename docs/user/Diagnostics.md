# Diagnostics / Tanılama

Diagnostics shows version, database check, output client count and source health. Provider request counts are operational counters for the current session, not billing estimates. Rate-limit values appear only when supplied by the provider. An unavailable value is shown as a dash.
Export diagnostics writes an allowlisted JSON report, excluding credentials, output URLs, source names, story content and databases. Send it to your support contact only after reviewing it.
Türkçe: Sürüm, veritabanı, çıkış bağlantıları ve kaynak durumunu inceleyin. İstek sayıları oturuma aittir ve fatura tahmini değildir. Tanılama dışa aktarma kimlik bilgilerini, adresleri, haberleri ve veritabanını içermez.
