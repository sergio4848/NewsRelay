# Rundown / Yayın akışı

Queue adds a story once to the rundown. Rows show order, priority, publisher, headline and template. Use up/down buttons with mouse or keyboard to reorder. Select a row for Preview. Remove affects the rundown, not the archived Incoming item. NEXT takes the first rundown item unless HOLD is active.
Incoming is capped at 500 stories and rundown at 200. Queued/preview/program items are protected from Incoming retention. The recent operational history displays up to 300 events; storage retains 2,000. Back up your database if long-term retention is required.
Türkçe: Sıraya al ile haber ekleyin. Yukarı/aşağı düğmeleriyle sırayı düzenleyin. Satıra tıklamak Önizleme’yi açar. SONRAKİ ilk haberi yayına alır. Akış yeniden başlatma sonrası korunur; yayın otomatik başlamaz.
