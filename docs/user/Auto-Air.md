# Auto-Air / Otomatik yayın

Manual: nothing is automatically queued or taken.
Assisted: enabled Official/Trusted sources enter the rundown; TAKE remains an operator action.
Auto-Air: only enabled Official/Trusted sources with Allow Auto-Air and sufficient priority can advance automatically. Rules are checked at each transition. Ineligible stories remain for operator review. A mode selection alone does not approve a source.
Use HOLD to pause progression. CLEAR disarms Auto-Air. Restart returns to Manual and blank output. Always rehearse rules in an isolated Demo workspace before enabling unattended playout.
Türkçe: Manuel modda otomatik sıralama/yayın yapılmaz. Destekli mod güvenilir haberleri sıralar, yayına alma operatördedir. Otomatik yayın için kaynak etkin olmalı, Resmî/Güvenilir olmalı, ayrıca izin ve yeterli öncelik bulunmalıdır. TEMİZLE veya yeniden başlatma otomatik yayını durdurur.
