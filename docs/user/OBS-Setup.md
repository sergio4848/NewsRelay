# OBS Setup / OBS kurulumu

1. In Settings → OBS Browser Output, choose Copy URL.
2. In OBS add a Browser Source and paste it.
3. Set width 1920 and height 1080. The background is transparent.
4. Keep the source active when hidden. Do not add an opaque custom background.
5. Copy test URL for a separate rehearsal source; it never changes live Program. Remove/hide that rehearsal source before transmission.
   The output runs independently of the desktop section you view. Temporary connection loss retries automatically; after three failed checks it blanks rather than indefinitely retaining a stale headline. Restoring the service reconnects. A normal restart uses the saved port and token. Refresh the browser source if required. Changing between Demo and Live requires the corresponding URL.
   Türkçe: Ayarlar’dan çıkış adresini kopyalayın, OBS’de Tarayıcı Kaynağına yapıştırın. Boyut 1920×1080, arka plan şeffaf olmalıdır. Test adresini ayrı bir prova kaynağında kullanın ve yayın öncesi gizleyin. Bağlantı kesilirse çıkış yeniden bağlanır; üç başarısız kontrolden sonra eski haber temizlenir.
