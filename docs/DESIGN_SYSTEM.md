# Design system
Flat dark control surface; Segoe UI system font, weights 400/500/600. Background #14181c, surface #1b2025, border #343c43, text #e6eaed, muted #9da8b2.
Red means on air/breaking/destructive. Green healthy. Amber hold/degraded. Neutral selection. Radius 3px, 8px spacing rhythm. No decorative gradients, blur, glow, marketing cards or emoji.
Control uses source/status rail, incoming list, separate Preview/Program monitors and a tabular rundown. Controls remain reachable at 1280×800; keyboard focus is visible. Ctrl+Enter TAKE, Ctrl+H HOLD, Ctrl+N NEXT, Ctrl+Shift+Backspace CLEAR. Ignore shortcuts in editable fields.
English and Turkish share typed keys; source content is not translated. Broadcast canvas 1920×1080 with bounded text, 80px safe margins and stable media geometry.
